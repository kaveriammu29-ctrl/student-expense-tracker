# Student Expense Tracker

A small React + Vite project to record daily expenses and track a student's budget.

## Features
- Set a monthly budget
- Add expenses with amount, category, date, and note
- View total spent and remaining budget
- Filter expenses by category
- Delete an expense
- Save data in browser localStorage

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown in the terminal (usually http://localhost:5173).

## Note
This is a front-end academic demo. Budget and expense data are saved in the current browser using localStorage. No backend or database is connected.
